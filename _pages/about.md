Software engineer interested in how LLMs work under the hood. I've been building things from scratch to learn — starting from word embeddings and working up to a full inference engine with GPU kernels.

The [from-scratch series](/projects/) covers the path I took: Word2Vec, RNN/LSTM, Transformer, GPT-2, and finally an inference engine with KV-cache, PagedAttention, and Flash Attention. Each project loads real weights and produces real output.

I write about what I learn along the way.
