A language model built from scratch implementing next-token prediction using n-gram statistics and probability ranking.

### Key Features
- N-gram frequency analysis for vocabulary search
- Beam-search inspired ranking algorithm
- High-probability completions surfaced in O(log n) time
- Implements core concepts underlying modern autoregressive LLMs
